# ARF V1 Archive

This directory preserves selected code, figures, aggregate result tables, and the recorded environment file from the original RD-Agent study.

It supports inspection of the experimental methodology and the aggregate findings reported in ARF V1. It is not a standalone public runtime: the archived scripts depend on raw task data, intermediate caches, `learning_records/`, and individual-level outputs that are intentionally excluded from this release.

For the publicly reproducible evaluation workflow, data boundary, and current verification instructions, see the repository-root README and the ARF V2 materials.
