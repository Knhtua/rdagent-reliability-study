# Reports

This directory contains the final English reports prepared for the public release of this project.

- [ARF V1 Project Report](ARF-V1-Project-Report-English.pdf) documents the original RD-Agent project study and follow-up analyses.
- [ARF V2 Reliability Report](ARF-V2-Reliability-Report-English.pdf) documents the independent reliability evaluation, including nested cross-validation, calibration analysis, uncertainty analysis, and limitations.
- [Public release note](PUBLIC_RELEASE_NOTE.md) defines the materials included in and intentionally excluded from this release.

The archived V1 directory retains selected code, figures, and aggregate result tables for inspection of the experimental record. Its scripts depend on inputs and intermediate records that are intentionally not included in the public release; see [the archive boundary note](../archive/arf_v1/README.md). Raw clinical data and participant-level information are not included.
